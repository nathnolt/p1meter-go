Always-on devices

Things that run all the time. Their total wattage is subtracted from the power and electricity-used panels (power, imported kWh, power/usage from the import meter), so what is left shows the other devices. Per-phase power is reduced too: “any phase” devices come off every phase in full, a device set to L1, L2 or L3 only off that phase. The tiles at the top (electricity import, cost, peak and average power) are deducted as well. Exported energy and meter readings are not changed.

Start a new log
